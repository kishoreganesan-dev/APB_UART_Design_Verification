# APB-Based UART Controller – Design Verification

## Project Overview
This project focuses on the design and functional verification
of an APB-based UART Controller using Verilog and SystemVerilog.

The project is currently under development.

## Project Objectives
- Understand APB protocol
- Design UART Transmitter and Receiver
- Implement FIFO functionality
- Develop a self-checking testbench
- Perform functional verification

## Tools and Technologies
- Verilog
- SystemVerilog
- Siemens Questa (planned for simulation)
- Visual Studio Code
- Git and GitHub

## Current Implementation Status
- APB interface prototype
- APB slave register prototype
- UART transmitter prototype
- Basic testbench development

## Planned Features
- UART Receiver
- TX and RX FIFO
- APB-UART integration
- Self-checking testbench
- Assertions and functional coverage
- UVM-based verification
